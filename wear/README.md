# חשבון קשט — אפליקציית Wear OS

עטיפה נייטיב סביב גרסת השעון שב-`watch/`. הדף עצמו הוא ה-UI; האפליקציה מוסיפה
את מה שדפדפן לא יכול לתת: אייקון אמיתי, פתיחה בלחיצה אחת, Tile ו-Complication.

## מבנה

| רכיב | תפקיד |
|---|---|
| `MainActivity` | WebView שטוען את `watch/` מתוך `assets/` דרך `WebViewAssetLoader` |
| `SamCalendar` | קורא את קבצי ה-`.dat` (base64 + XOR) — אותו פענוח בדיוק כמו ב-JS |
| `TodayTileService` | Tile: התאריך השומרוני והמועד הקרוב, בהחלקה ממסך השעון |
| `TodayComplicationService` | Complication: התאריך על מסך השעון עצמו |

## החלטות תכנון

**הדף נטען מ-`assets/`, לא מהרשת.** פתיחה מיידית, ועובד לגמרי בלי חיבור כבר
מההפעלה הראשונה. `WebViewAssetLoader` מגיש אותו מ-origin של `https://`, כך
ש-`localStorage` וה-service worker מתנהגים כרגיל.

**הנתונים לא קופאים בזמן הבנייה.** בכל הפעלה רץ ברקע רענון של קבצי השנה
מהאתר החי אל `filesDir`, ו-`shouldInterceptRequest` מעדיף אותם על פני
המצורפים. העדכון נכנס לתוקף בהפעלה הבאה — כדי שלא ישתנו נתונים באמצע שימוש.

**רק שלוש שנים נארזות** (`y-1…y+1`, מחושב בזמן הבנייה) — כמה מאות KB במקום
103MB של `cal/`.

**צורת המסך מועברת ב-URL.** `Configuration.isScreenRound` אמין; שאילתת
ה-CSS `(shape: round)` לא נחשפת ב-WebView רגיל.

**ניווט בהקשה מופעל** (`nav=tap`). Wear OS שומרת לעצמה את ההחלקה האופקית
עבור מחוות הסגירה, ולכן אסור שהניווט יסתמך רק עליה. החוגה הסובבת מטופלת
ב-Kotlin ומוזרקת לדף.

## בנייה

ה-APK נבנה אוטומטית ב-GitHub Actions בכל דחיפה שנוגעת ב-`wear/` או ב-`watch/`.
מורידים אותו מלשונית **Actions** ← ההרצה האחרונה ← ארטיפקט `sam-calendar-wear-debug`.

מקומית (דורש Android SDK):

```bash
cd wear
gradle assembleDebug
```

## התקנה על השעון

ה-APK אינו חתום לחנות, ולכן מתקינים ב-sideload. ניפוי דרך Bluetooth הוסר
ב-Wear OS 3, וההתחברות היא דרך Wi-Fi בלבד — השעון והמחשב חייבים להיות
באותה רשת.

בשעון:

1. הגדרות ← מידע (About watch) ← הקשה 7 פעמים על **מספר גרסה** (Build number)
2. הגדרות ← אפשרויות מפתח ← הפעלת **ADB debugging**
3. הגדרות ← אפשרויות מפתח ← הפעלת **Wireless debugging**
4. בתוך Wireless debugging ← **Pair new device** — מוצגים קוד בן 6 ספרות,
   כתובת IP ופורט התאמה

במחשב (דורש adb מגרסה 30 ומעלה):

```bash
adb pair <IP>:<פורט-ההתאמה>      # ואז מקלידים את הקוד בן 6 הספרות
adb connect <IP>:<פורט-החיבור>    # פורט החיבור שונה מפורט ההתאמה!
adb devices                       # לאימות
adb install -r app-debug.apk
```

**פורט ההתאמה ופורט החיבור אינם זהים.** פורט ההתאמה מופיע רק במסך
«Pair new device», ופורט החיבור במסך Wireless debugging עצמו.

בלי מחשב: אפשר להשתמש ב-**Wear Installer 2** על טלפון אנדרואיד — היא
מכילה adb משלה ומתקינה APK מתיקיית ההורדות של הטלפון אל השעון.

לאחר ההתקנה: להוספת ה-Tile — החלקה שמאלה ממסך השעון ← `+` ← «הלוח השומרוני».
להוספת ה-Complication — לחיצה ארוכה על מסך השעון ← עריכה ← בחירת משבצת.
