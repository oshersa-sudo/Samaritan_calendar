# קערת כף תמר עם תמרים – מודל להדפסה תלת־ממדית (Bambu Lab P2S)

כף עץ דקל (תמר) פרוסה כקערה קעורה רדודה, עם אמצעית מורמת ועורקי עלעלים,
ומסביב טבעת של 16 תמרים השקועים חלקית בעלה.

| קובץ | תוכן |
|---|---|
| `date_palm_bowl.3mf` | אובייקט אחד עם שני חלקים (עלה + תמרים), צבעים מצורפים – **הקובץ המומלץ** |
| `date_palm_bowl_leaf_green.stl` | העלה בלבד (ירוק) |
| `date_palm_bowl_dates_gold.stl` | התמרים בלבד (זהב) |
| `preview.png` | תצוגה מקדימה |
| `generate_date_palm_bowl.py` | הסקריפט שמייצר את המודל (ניתן לשנות מידות/מספר תמרים) |

## מידות
- גודל: ‎179 × 120 × 44‎ מ"מ (נכנס בקלות למשטח 256 מ"מ של ה־P2S)
- עובי דופן: 3 מ"מ, תחתית שטוחה (אליפסה 120 × 66 מ"מ) ליציבות על המשטח
- שיפוע הדופן מתחיל ב־45° ומתחדד לכיוון השפה – מיועד להדפסה **ללא תמיכות**
- התמרים: ‎19 × 10‎ מ"מ, שקועים כ־2 מ"מ בעלה כך שהם מתמזגים איתו בהדפסה

## הדפסה ב־Bambu Studio
1. פתחו את `date_palm_bowl.3mf` (File → Import). הקובץ נטען כאובייקט אחד עם שני חלקים.
2. ב־AMS הגדירו פילמנט ירוק ופילמנט זהב (למשל PLA Metallic Gold).
3. בעץ האובייקטים, לחצו על החלק "Palm leaf (green)" ובחרו את הפילמנט הירוק,
   ועל "Dates (gold)" את פילמנט הזהב.
4. מומלץ: גובה שכבה 0.16–0.2 מ"מ, 3 קירות, ללא תמיכות, Brim לא נדרש.
   אם רוצים להפחית החלפות צבע: התמרים נמצאים רק בחלק העליון של ההדפסה,
   כך שההחלפות מתרחשות רק בשכבות האלה.

אם מעדיפים STL: ייבאו את שני קבצי ה־STL יחד ואשרו "Load as a single object with multiple parts"
כדי שיישמרו במקומם זה ביחס לזה.

## שינוי המודל
הפרמטרים נמצאים בראש `generate_date_palm_bowl.py` (מידות, עומק, מספר תמרים, גובה העורקים).
הרצה: `python3 generate_date_palm_bowl.py` (דורש `numpy shapely trimesh triangle matplotlib`).
